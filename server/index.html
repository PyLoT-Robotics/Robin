Download root CA

1. Install on iPhone

  1. Download rootCA.pem above and allow the configuration profile download.
  2. Open Settings → Profile Downloaded, or General → VPN & Device Management, then install the profile.
  3. Open General → About → Certificate Trust Settings and enable full trust for the mkcert root certificate.
  4. Return here and tap Recheck trust. Reopen the page if Safari kept the previous connection.

2. Connect Robin

  1. Copy the large robot IP shown above.
  2. Open the hosted Robin client.
  3. In Settings → Robin Server Local IP, paste the IP and save.
  4. Robin will use secure ROS and video routes on port 5173.

Android certificate setup

Download the root CA, then use Android Settings to install it as a CA certificate. The exact menu differs by manufacturer; it is commonly under Security, Encryption & credentials, or Install a certificate.
